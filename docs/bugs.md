## Зауваження до коду та прийняті зміни

1. `backend/prisma/schema.prisma`: імпорти генерованого клієнта мають відповідати
   JavaScript, який реально запускає Node. Генеровані файли вручну не редагуються.
2. `backend/src/auth/dto/register.dto.ts`: нормалізація name/email має відбуватися
   до валідації; інакше критерії приймання перевіряють інше значення, ніж БД.
3. `backend/src/recommendations/match.ts`: чисту бізнес-логіку винесено з контролера,
   щоб перевіряти поріг і порожні дані без БД та HTTP.
4. `frontend/src/api.ts`: HTTP-статус зберігається у типізованій помилці; Dashboard
   визначає 401 за статусом, а не за текстом локалізованого повідомлення.
5. `backend/package.json`: усунуто дубльований ключ scripts; усі Prisma-команди
   явно отримують нестандартний файл `prisma7.config.ts`.
